Use Python's standard library and the system OpenSSH programs. Run `python -m unittest discover -s tests -v`. Forwarding-policy or supervisor changes also need the disposable Linux integration job. Examples must use fictional addresses and generated test data. Keep endpoint keys, machine names, operational logs and credentials outside Git. Record changes and validation in DEVELOPMENT_LOG.md.

For user setup and diagnostics start with [the noninteractive interface](docs/ai.md). Inspect `capabilities`, `preflight`, and `status` before changing anything. To test alongside an existing installation use a separate state directory and an unused local port. Test roaming with `python tests/roaming_smoke.py` after installing the test-only Paramiko and cryptography dependencies. Runtime and the control page use only the standard library.
